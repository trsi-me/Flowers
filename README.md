# متجر الورد

## 1 ما هو المشروع

متجر ويب لعرض أصناف الورد وأسعارها من قاعدة MySQL، مع سلة في المتصفح وصفحة دلائل ثابتة. عنوان الصفحة في `index.php`: «متجر الورد - بيع الورد أونلاين».

## 2 لماذا وُجد

نص قسم «من نحن» في `index.php` يصف المتجر بأنه متخصص في بيع الورد الطبيعي، ويذكر توصيلاً خلال 24 ساعة وورداً طبيعياً وضمان جودة. لا يوجد في الملفات طلب شراء أو شحن فعلي يربط هذه العبارات بعملية مكتملة.

## 3 المستخدمون

زائر المتصفح. لا جداول مستخدمين ولا تسجيل دخول في `database.sql`.

## 4 القدرات

| القدرة | أين تظهر |
| --- | --- |
| عرض المنتجات من جدول `products` | `index.php` |
| إضافة معرف المنتج إلى مصفوفة `cart` في الذاكرة | `addToCart` في `script.js` |
| تحديث الرقم بجانب أيقونة السلة | `updateCartCount` |
| فتح تبويبات الدلائل | `showGuide` في `guides.php` |
| روابط أقسام: الرئيسية، المنتجات، من نحن، الدلائل، اتصل بنا | شريط `index.php` |

## 5 كيف يعمل

1. `index.php` يستدعي `config.php`.
2. الاتصال يتم عبر PDO إلى قاعدة `flower_store`.
3. الاستعلام `SELECT * FROM products ORDER BY id` يملأ الشبكة.
4. زر «أضيفي للسلة» يستدعي `addToCart(id)` في المتصفح فقط.
5. `guides.php` صفحة HTML ثابتة بثلاثة تبويبات، بلا استعلام قاعدة.

## 6 أمثلة واقعية

دالة `addToCart(productId)` في `script.js` تضيف الرقم إلى المصفوفة `cart` ثم تستدعي `updateCartCount()` وتعرض `alert` بالنص «تم إضافة المنتج للسلة بنجاح!». إعادة تحميل الصفحة تعيد العداد إلى 0 لأن `DOMContentLoaded` يستدعي `updateCartCount` على مصفوفة فارغة جديدة.

`showGuide(guideId)` يبدّل الصنف `active` بين التبويبات: `start` و`marketing` و`instagram`.

## 7 رحلة المستخدم

الزائر يفتح `index.php`، يرى المنتجات الستة البذرية، يضغط «أضيفي للسلة»، يظهر تنبيه ويزيد العداد. يمكنه فتح `guides.php` وقراءة دليل البدء أو التسويق أو إنستغرام. قسم الاتصال يعرض هاتفاً وبريداً وحساب إنستغرام كنص ثابت بلا نموذج إرسال.

## 11 الأتمتة

## 12 أثر الوحدات على بعضها

`index.php` يعتمد على نجاح اتصال `config.php`. فشل الاتصال يوقف الصفحة عبر `die` مع نص الاستثناء. السلة في `script.js` لا تكتب في `products` ولا تقرأ السعر. `guides.php` مستقل عن قاعدة البيانات ويشترك مع المتجر في `style.css` وخط IBM Plex Sans Arabic وFont Awesome.

## 18 الواجهة الأمامية

اتجاه الصفحة `rtl` واللغة `ar`. الأقسام: `home` و`products` و`about` و`contact`. بطاقة المنتج تعرض الاسم والوصف والسعر بالريال وشارة «جديد» الثابتة لكل البطاقات. `guides.php` يكرر شريطاً أقصر بلا سلة. لا وسم `link rel="icon"` في الصفحتين.

## 19 الواجهة الخلفية

الخلفية هي `config.php` واستعلام القراءة في `index.php`. لا مجلد `api`. معالجة الأخطاء في الاتصال تطبع رسالة `PDOException` للمتصفح.

## 20 تدفق الطلب

مثال حقيقي لفتح المتجر:

```
GET /index.php
  -> require config.php
  -> PDO mysql:host=localhost;dbname=flower_store;charset=utf8mb4
  -> SELECT * FROM products ORDER BY id
  -> حلقة foreach تبني .product-card
  -> المتصفح يحمّل script.js
```

الضغط على منتج «الورد الأحمر» (السعر البذري 150.00) يستدعي `addToCart` بمعرف الصف، بلا طلب HTTP جديد.

## 21 جداول قاعدة البيانات

قاعدة `flower_store`. جدول واحد:

| العمود | النوع في `database.sql` |
| --- | --- |
| id | INT AUTO_INCREMENT PRIMARY KEY |
| name | VARCHAR(100) NOT NULL |
| description | TEXT |
| price | DECIMAL(10,2) NOT NULL |
| image_url | VARCHAR(255) |
| created_at | TIMESTAMP DEFAULT CURRENT_TIMESTAMP |

البذرة: ستة صفوف (أحمر 150، وردي 120، أبيض 130، أصفر 110، برتقالي 140، بنفسجي 160).

## 24 ضوابط الأمان الموجودة فعلياً

## 30 التثبيت

1. تشغيل MySQL وخادم PHP.
2. استيراد `database.sql` (ينشئ `flower_store` وجدول `products` والصفوف الستة).
3. مطابقة قيم `config.php` مع خادم MySQL المحلي.
4. فتح `index.php` من جذر الويب.

## 31 دليل التطوير

المشروع مسطح في الجذر. تعديل المنتجات يتم في SQL أو بإدراج صفوف في `products`، لأن لا شاشة إدارة. تعديل السلة يتم في `script.js`. تنسيق المتجر في `style.css`، وتنسيق الدلائل مضمّن داخل `guides.php` بالإضافة إلى `style.css`.

## 32 النشر

## For Non-Technical Users

الموقع يعرض ستة أنواع ورد بأسعارها. زر السلة يزيد رقماً على الشاشة ولا يرسل طلباً للبائع. صفحة الدلائل شروح مكتوبة داخل الصفحة. أرقام الهاتف والبريد في قسم الاتصال للعرض فقط.

## For Developers

أضف أعمدة أو صفوفاً عبر SQL. أي حفظ للسلة يحتاج جدولاً ونقطة حفظ غير موجودين اليوم. عند عرض النصوص القادمة من القاعدة استخدم تهريباً مناسباً لـ HTML، فالصفحة الحالية تطبع الحقول مباشرة.
